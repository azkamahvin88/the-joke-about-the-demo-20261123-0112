A one-line joke about working beside AI coding agents: an agent that demos a feature with a video of it working — a video it had generated that morning. An AI judge compares entries pairwise, and the 20 best win rates share $50.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: the same fixed string on every run, no randomness, no clock, no network.
